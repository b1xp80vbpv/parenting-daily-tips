# 微刺激方案一般促起来几个优势卵泡？

> 更新时间：2026-09-10 (UTC+8)

长方案进行一半放弃了，在医生额建议下准备在下个月用微刺激方案了，医生说我卵巢储备还可以，可是用药后低反应，左右卵泡不均匀，还少，大小共7个，请问大家微刺激方案一般取多少个？微刺激方案一般促起来几个优势卵泡呢？有姐妹可以分享一下吗？

微刺激方案的取卵个数一般是1-3个，能促成几个优势卵泡具体还要看基础卵泡的质量了，但试管微刺激方案成功率还是比较高的。这种方案一般用于卵巢功能较差，年龄比较大的女性，通过使用少量的促排药，促进卵泡发育和排卵的过程，一般促成的卵泡是在3个左右，多的也有8、9个，如果使用微刺激方案发现卵泡数量少，达不到预期，也可使用其他的方法，比如自然周期、拮抗剂方案等，但是需要结合自己的实际的情况在，在医生的指导线选择适合自己方案。

微刺激方案没有降调的过程，获得优势卵泡可能没有其他方案的那么多，但是对女性产生危险的可能性比较小，也是最接近自然妊娠的方法，接下给大家详细介绍微刺激方案的流程：

- 1. 微刺激方案一般会在月经第二天监测卵泡，和查性激素六项；
- 2. 检查达标的话在月经第二天口服促排卵药物或小剂量针剂，一般使用克罗米芬、来曲唑等促排药物，针剂使用剂量一般不超过150u/日，直到收针为止；
- 3. 微促排期间需要观察卵泡发育情况来增加或者减少药量，检查时间一般是在促排第5天，第8天，第10天；
- 4. 等检测卵泡达到18mm的时候进行予以绒促性素（HCG）夜针，夜针后36小时取卵，一般情况下取卵个数在2-3个左右。
微刺激方案对卵巢刺激小，疗程短，更安全，获得的卵子质量也更高，在临床上使用范围也更加广泛，但并不是所有患者都适合这个方案，做试管婴儿可以根据医生的建议选择适合自己的方案，这样才能提高怀孕的成功率。
