# 广州做试管婴儿一般需要什么证明？要多少钱？

> 更新时间：2026-09-11 (UTC+8)

生育这条充满挑战的道路上，试管婴儿技术为许多不孕不育家庭带来了希望的曙光。在广州，这项技术也备受关注，众多夫妻渴望借助它实现拥有宝宝的梦想。但在准备踏上试管征程前，大家总会被一个关键问题困扰：广州做试管婴儿一般需要什么证明？毕竟，清晰了解所需证明，是顺利开启求子之旅的重要前提。接下来，我们就一起深入探讨，帮大家理清头绪。

1. 结婚证、身份证、准生证（计划生育服务证明）；

2. 女方病史、手术史以及不育病史的临床检查及治疗经过材料，由于输卵管因素不孕者，还需提交输卵管检查记录；

3. 监测女性基础性激素，并进行盆腔B超检查阴道分泌检查，必要时还要进行子宫内膜活检、宫颈细胞学检查，这部分材料用于了解女性子宫环境问题，用来衡量是否适合做试管婴儿；

4. 男方进行体检，提液的常规化验报告单；

5. 夫妇双方进行乙肝病毒、丙肝抗体、艾滋病抗体、梅毒血清学、肝功能、血型检查等检查报告，女方还要进行血沉、血常规、尿常规、凝血功能、心电图、染色体等检查。

广州做试管婴儿一般需要多少钱

广州试管婴儿费用大概要3-8万：

1. 促排卵（8k-2w）：每个人的自身情况不一样，促排用药情况也会不同，费用也会有所不同；

2. 试管手术（1w-2w）：*含**手术、移植手术，部分男性无法正常获精的，还需要进行取精手术；

3. 实验室培养（1w-3w）：具体看需要做几代试管，一代/二代试管只需要精子卵子结合，三代试管需要筛查费用就会贵很多；

4. 冷冻胚胎（1k-4k）：移植后多余的胚胎就需要进行冷冻，费用一般按季度或者年度算。
