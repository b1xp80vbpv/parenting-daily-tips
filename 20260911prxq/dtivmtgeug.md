# 指尖守护 科普之光——乳腺甲状腺外科科普团队斩获国家级科普大赛一等奖

> 更新时间：2026-09-11 (UTC+8)

近日，从中国医师协会医学科学普及分会甲状腺及疝科普学组2025全国科普大赛暨第五届潇湘乳甲科普大赛决赛现场传来好消息，**柳州市人民医院乳腺甲状腺外科团队创作的科普演讲作品《乳房健康在指尖——乳腺癌的预防》从****22支全国各地顶级医院的科普精英团队中脱颖而出，荣获一等奖**，标志着医院在健康科普领域的专业实力获得国家级权威认可。
**全国一等奖**
决赛现场强手如林，乳腺甲状腺外科团队代表李佶航副主任护师，凭借扎实的专业功底、自信从容的现场发挥、创新的呈现方式以及稳健的答辩，赢得了专业评委的高度认可与赞誉，最终摘得桂冠。

此次参赛作品紧扣“乳房健康自我检查”与“乳腺癌科学防治”两大核心议题，团队成员立足临床一线工作经验，精准把握女性群体在乳腺健康认知中的痛点与误区。

为将复杂的医学知识转化为通俗易懂的健康指南，参赛团队在完成日常临床、教学、科研工作的同时，利用业余时间反复打磨作品。从规范化自检手法教学到乳腺癌风险因素解读，从早期症状识别要点到动画演示设计，每个环节都经过数十次修改优化，最终形成兼具科学性与传播力的科普精品。

荣誉的取得离不开医院及科室对科普工作的系统性支持。乳腺甲状腺外科将健康科普视为重要使命，在人员调配、专业把关等方面提供便利，科室多名医务人员作为医学科普自媒体博主积极传播健康知识；医院充分发挥医务人员作为健康科普主力军作用，在资源整合、平台搭建等方面给予大力扶持，形成 “自发热情 + 组织赋能” 的良好模式。

下一步，医院将不断探索创新科普形式与内容，针对不同人群开展精准健康科普，扩大科普覆盖面与影响力，为提升全民健康素养贡献更多力量。

**乳腺甲状腺外科简介**

柳州市人民医院乳腺甲状腺外科于2005年独立建科，是集乳房疾病及甲状腺疾病的诊断、治疗、整形、科研、教学于一身的学科，以“最小的创伤治愈疾病和以最大的可能保留功能”为目标追求，现已形成“高素质的专业人才+先进的诊疗设备+人性化的服务理念+微创化的治疗效果”的专科服务特色。学科医师团队共有36人，其中博士后及博士14人（包括在读），博导1人，硕导6人，正高6人、副高3人，硕士研究生23人。

科室近五年获得国家级、自治区及市级科研项目10余项，获自治区及市级科研奖励8项，发表包括SCI及国家级核心期刊学术论文100余篇，获国家级专利20余项。拥有专业学科师资，教学成绩突出，近三年来招收及培养硕士研究生10多人，接收住培生近400人次，举办国家级及自治区级学习班10多个，多次在自治区举办的教学比赛中斩获佳绩，其中2020年获广西医科大学第12届青年教师教学基本功比赛获一等奖、广西医科大学护理学院临床教师授课比赛获第一名。

**乳腺甲状腺外科常规开展以下特色诊疗项目：****一是**规范、熟练开展乳腺癌的常规手术，包括各种早中晚期乳腺癌手术治疗术式以及II期乳房重建术等。**二是**开展乳腺美容与整形术，包括乳房再造术、乳头及乳晕再造术、乳房缩乳术等。**三是**针对小于2.5cm乳腺良性肿物，采用先进真空辅助活检技术，使良性病灶在局麻下完成切除，住院周期短。**四是**开展乳腺癌综合治疗服务，包括中晚期乳腺癌的新辅助化疗、手术、术后放化疗、内分泌治疗、靶向治疗、药物去势治疗、特色术后康复治疗等系列综合全方位治疗。**五是**开展腔镜下甲状腺微创手术，包括经口腔途径、胸乳途径、腋窝途径等的充气或免充气术式等。
