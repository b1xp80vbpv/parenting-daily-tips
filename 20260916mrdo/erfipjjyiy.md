# 好消息，北海市人民医院开通手机预约医技检查功能

> 更新时间：2026-09-16 (UTC+8)

为了给患者提供更加便利的就医服务，进一步改善患者的就医体验。我院开通线上**“医技预约”**功能，**超声检查和磁共振检查**均可通过线上进行预约检查。 门诊患者由医生开具检查医嘱后，通过手机登录进行线上预约，住院患者由病区护士帮助预约。预约流程如下：**第一步**手机登录微信扫码进入“北海市人民医院智慧医院”小程序。或者登录微信或支付宝，点击搜索框，点击小程序，在搜索框中输入“ 北海市人民医院智慧医院”。

[ 图片滑动 ]**第二步** 进入“北海市人民医院智慧医院”小程序，找到“医技预约” 点击“待预约”

[ 图片滑动 ]

**预约有两种方式：a.普通预约    b.一键预约**
**普通预约**点击开始预约，选择日期，选择检查的时间，点击确认，显示状态，这个界面可以取消预约，也可以修改预约

[ 图片滑动 ]

**一键预约**点击一键预约，里面有两个选择

[ 图片滑动 ]
**推荐最早：**系统自动推荐最早能做检查的时间

**推荐同天：**系统自动推荐同天能做检查的时间（如果患者一次开多个检查，并且患者需要把这多个检查安排在同一天做，那么系统就会自动推荐能当天一起做的日期推送给患者）

选择推荐方式后，页面出现“待确认”单子，如果系统推荐的时间合适，点击“确认”来确认以此时间预约，否则可以点击“修改预约”或者“取消预约”重新选择预约。

**注意：**请及时确认预约，系统只锁号5分钟，超过5分钟不确认，系统释放号源。
**已预约查询**点击“预约查询”可进行预约查询、修改预约和取消预约，点击其他地方可显示更详细的信息。预约成功后，请按预约时间准时到医院医技楼进行检查。
