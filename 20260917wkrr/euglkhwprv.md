# 勿以“疝”小而不为

> 更新时间：2026-09-17 (UTC+8)

何谓**“疝”**？

医学上“疝”指的是

体内脏器或组织离开其正常解剖部位

通过先天或后天形成的薄弱点、缺损或孔隙

进入另一部位

啊哈！~

原来“疝”就是“出轨”！

这“出轨”的病得治

所以

锋哥说“勿以疝小而不为”

疝气的危害很多

疝气反复突出影响工作、生活和学习

影响患儿生长发育

出现局部疼痛、消化不良

严重的嵌顿疝可引起肠梗阻、肠坏死

危及生命

噢，原来这**“疝气”**

来者不善！

  //  

外科医生会根据病情选择不同的手术方式，疝气的手术方式主要有三大类：

一是传统的疝囊高位结扎及疝修补术

二是无张力的疝修补术

三是腹腔镜微创疝囊高位结扎及疝修补术

一般来说，儿童行开放或腹腔镜疝囊高位结扎即可，手术比较简单，术后1-2天就出院了。

（术前缺损）

（高位结扎术后缺损关闭）

成人需要行疝修补术，为了减轻术后疼痛、减少复发，大多数患者会选择微创的腹腔镜无张力修补术。

当然，不能会做腹腔镜手术，就忘了开放手术。遇到高龄、心肺肝肾功能不全的患者，无法进行全身麻醉怎么办？

南平市人民医院普外科通过20年临床实践总结出髂腹下神经、髂腹股沟神经及生殖股神经阻滞麻醉方法，以最小的、有效的麻醉安全地进行开放疝修补术，解决了老龄患者疝气“出轨”的烦恼

  //  

中医药的运用在“疝气”也的防治上是举足轻重的，古代医者在《儒门事亲》中描述：“狐疝，卧则入小腹，行立则出小腹入囊”。精诚治“疝”，不论是开放手术，还是腹腔镜微创手术，疝的手术都是非常精细而艺术的。

记得有一位大师说过，如果外科所有的手术只有疝手术，也可以为之奋斗一生

勿以“疝”小而不为，有两层意思。一是

患者得了“疝气”，要尽早手术。二是外科医生也不要因为“疝气”是小手术，就不努力学习、钻研。

医者要牢记“治病救人”的初心。
