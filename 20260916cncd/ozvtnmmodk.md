# 赤峰学院附属医院举办40周年院庆 暨赤峰市口腔医院成立庆祝大会

> 更新时间：2026-09-16 (UTC+8)

赤峰学院附属医院举办40周年院庆

暨赤峰市口腔医院成立庆祝大会

四十载沧桑砺洗，春华秋实；

四十载仁心不改，薪火相传。

10月18日上午，赤峰学院附属医院建院40周年暨赤峰市口腔医院成立庆祝大会在院本部隆重举行。内蒙古自治区卫生健康委副主任王占国、医改医管局局长曹铁军，赤峰市人大主任邹德华、市政府副市长李志刚、市政协副主席李自学、市委副秘书长王秀军、市政府副秘书长王立丛，赤峰学院党委书记王玉树、校长雷德荣、副书记于毅夫、副校长袁德忠、副校长徐振军、市卫健委主任孟和巴特尔出席会议。赤峰学院原党委书记郑克、原纪委书记刘显文、原纪委书记于建设、原副校长德力格尔、原副校长倪清柏、原副校长贾国富、原副校长附属医院原院长崔其福，医院原院长吴桂珠、原党总支书记刘守银、原党委书记王凯、院长张丽敏在主席台就座；大会由医院党委书记李占则主持。市直各委办局、赤峰市各社会团体和松山区政府领导出席会议；医院部分老领导、老同志及职工代表和全市医疗机构同仁共襄盛会。

在庄严的中华人民共和国国歌声中，大会开始各项议程。

 医院院长张丽敏致辞
   张丽敏院长为大会致辞。带领大家回顾了附院40年风雨砥砺、奋斗不息的发展历程，她强调，技术为先，方能立于行业前沿；质量为基，方能行稳致远；服务为本，方能肩负起责任担当；人才为要，方能固本强基；科技为锋，方能不断创新突破；党建为纲，方能坚守初心；文化为魂，方能使附院品质历久弥新！

张院长表示，附属医院建院40周年，恰逢决胜全面建成小康社会和“十三五”规划收官之年，也是保障“十四五”规划顺利起航的奠基之年，在这个承前启后的关键时期，全员职工将坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻落实“健康中国”战略，聚焦人民群众对卫生健康的新需求、新期待，提升医疗服务和医院管理水平，完善应急管理体系，抓紧抓实抓细常态化疫情防控，加强人才培养，全体附院人将以“只争朝夕、不负韶华”的奋斗姿态，努力打造蒙东地区医教研中心，为健康赤峰建设、为学院实现赤峰大学奋斗目标作出新贡献。

医院党委书记李占则主持会议

曹铁军局长宣读关于成立赤峰市口腔医院的批复文件

赤峰市口腔医院揭牌成立

曹铁军局长宣读关于成立赤峰市口腔医院的批复文件，王占国主任、邹德华主任、王玉树书记和孟和巴特尔主任共同为赤峰市口腔医院成立揭牌。

雷德荣校长致辞

雷德荣校长在致辞中对附院寄予厚望，他表示，赤峰学院是附院40年发展成就的见证者和参与者，从蹒跚学步的幼儿成长为健步疾行的壮年，从默默无闻到跻身三甲行列，医院发展按下了“快进键”，跑出了“加速度”，医疗、教学、科研各项工作取得突破性进展，赤峰市口腔医院成立就是最好的例证。希望附院把握机会，乘势而上，为赤峰地区卫生健康事业发展作出新的贡献。

李志刚副市长致辞

李志刚副市长向医院发表庆贺致辞，他指出，今天赤峰学院附属医院建院40周年，也是赤峰市口腔医院挂牌成立的日子，市口腔医院的成立，填补了我市没有公立口腔医院的空白，为赤峰市口腔医学发展注入新的动力和活力，对加快赤峰市口腔医学事业发展、增进全市人民群众口腔健康福祉必将起到重要的推动作用。

忆往昔，杏林初蕊，筚路蓝缕；看今朝，岐黄新姿，朝气蓬发。今天，赤峰学院附属医院又站在了新的历史起点上，全院职工将秉鲲鹏之志，乘浩荡长风，戮力同心，开拓进取，为健康赤峰建设作出更大贡献。
